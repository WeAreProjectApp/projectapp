# PA-246 · Títulos de documentos históricos

El resumen compartido agrega title: título del documento, archivo vinculado,
última revisión y, como último recurso, Documento #ID. source_key permanece como
identificador interno y nunca decide la etiqueta. Un título real original-6 se
respeta. El componente compartido por Propuestas y Gestor usa ese título; con
una API anterior puede resolverlo desde las revisiones disponibles.

No hay migración ni renombrado: IDs, archivos, versiones, selección y URLs no
se escriben. La lectura MCP de la misma identidad incluye el título.

Pruebas preparadas para CI: retirar un anexo mediante una nueva revisión y
comprobar título compartido/bytes/ID; representación histórica fuera del paquete,
respuesta antigua, título real con aspecto técnico, ausencia de título y recarga
de las dos superficies. Los HTTP simulados sólo acreditan UI; el backend prueba
la transición y persistencia reales sobre datos temporales. En esta base, el
caso backend retira el anexo archivando su fuente antes de confirmar el paquete;
la retirada por selección se comprueba sobre el corte integrado de PA-216.

DEV/Chrome pendiente en corte propio: coordinar con la dupla y registrar SHA,
rol y datos ficticios. Usar un anexo de prueba, confirmar una vez su retiro del
paquete vigente y recargar Propuestas y Gestor. Verificar título junto a Histórico,
URLs e IDs, encabezado, versiones y descarga. Probar ambos temas y cinco perfiles.
No reutilizar ni modificar el expediente histórico de PA-216. Si el corte aún no
incluye su selección de anexos, declarar esa dependencia al preparar el caso.
Teclado dedicado fuera del alcance manual.
